Debug Loop Breaker

The free sample. Complete, not a teaser paragraph.

Reproduce first

Prompt 1 forbids edits. The agent must write the steps, the expected result, the actual result, and one hypothesis — then wait for your yes.

One change at a time

No refactors, no file replacements, no new library to paper over a logic bug. Re-run the same steps after each attempt.

Stop after two failures

A third silent rewrite is how the hole gets deeper. The playbook makes the agent write a brief and wait for evidence instead.

Scope guard included

An always-on rule that stops the agent rewriting working files, expanding the brief, or saying “done” without running anything.

Install

About two minutes, then start a new agent chat.

  1. Clone or download this repository.
  2. Copy the two .mdc rules into your project’s .cursor/rules/ folder.
  3. Copy templates/AGENTS.md to your project root if you do not already have one, fill in the brackets, and paste the agent sections.
  4. Open playbooks/03-debug-loop-breaker.md and paste Prompt 1.
mkdir -p .cursor/rules
cp rules/02-scope-guard.mdc .cursor/rules/
cp rules/03-debug-loop-breaker.mdc .cursor/rules/
